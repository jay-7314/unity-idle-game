# Monster Idle

몬스터를 터치해 골드를 모으고, 업그레이드로 성장시키는 Unity 방치형 모바일 게임입니다.
Android에서 직접 실행해 확인했습니다.

## 구현한 기능

- **터치와 피드백:** 몬스터를 누르면 골드가 오르고, 눌림 스케일 효과와 떠오르는 `+N` 텍스트, 효과음이 나옵니다.
- **업그레이드:** 터치 강화(터치당 골드 증가)와 자동 수입(초당 골드 증가) 두 종류를 구매할 수 있습니다.
- **저장과 불러오기:** 골드와 업그레이드 레벨을 JSON으로 저장하고, 앱을 다시 켜면 복원합니다.
- **오프라인 보상:** 앱을 꺼 둔 시간만큼 자동 수입을 지급하고, 복귀 시 팝업으로 보여 줍니다. 최대 8시간까지 지급합니다.

## 설계 포인트

- **ScriptableObject 기반 데이터:** 업그레이드의 이름, 종류, 기본 비용, 비용 증가율, 레벨당 효과를 `UpgradeData` 에셋으로 분리했습니다. 코드를 고치지 않고 에셋만 추가해 업그레이드를 늘릴 수 있는 구조입니다.
- **비용 공식:** `비용 = 기본 비용 × 증가율^레벨` (반올림). 현재 기본값은 터치 강화 10, 자동 수입 25, 증가율은 둘 다 1.15입니다.
- **오브젝트 풀링:** 터치마다 생기는 떠오르는 텍스트를 생성과 삭제 대신 `UnityEngine.Pool.ObjectPool`로 재사용합니다.
- **저장 시점:** 구매할 때, 10초마다, 앱이 백그라운드로 갈 때와 종료될 때 저장합니다. 모바일에서 앱이 바로 종료될 수 있어 `OnApplicationPause`에서도 저장합니다.
- **카드 UI 분리:** `UpgradeCard`는 표시와 버튼 입력만 맡고, 구매 판단과 계산은 `IdleGame`이 맡습니다.

## 기술 스택

- Unity 6.3 LTS (6000.3.8f1), 2D URP
- C#, uGUI, TextMeshPro
- 저장: PlayerPrefs + JsonUtility

## 스크립트 구성

| 파일 | 역할 |
|---|---|
| `IdleGame.cs` | 골드, 구매, 자동 수입, 저장과 불러오기, 오프라인 보상 |
| `UpgradeData.cs` | 업그레이드 데이터(ScriptableObject)와 비용 계산 |
| `UpgradeCard.cs` | 업그레이드 카드 UI 표시와 버튼 연결 |
| `FloatingText.cs` | 떠오르며 사라지는 텍스트 |
| `MonsterTapEffect.cs` | 터치 시 몬스터 눌림 효과 |
| `SaveData.cs` | 저장용 데이터 구조 |

## 실행 방법

- **APK:** [Releases](../../releases)에서 `IdleGame.apk`를 받아 Android 폰에 설치합니다. (출처를 알 수 없는 앱 설치 허용이 필요합니다.)
- **에디터:** Unity 6000.3.8f1로 프로젝트를 열고 `Assets/Scenes/SampleScene`을 실행합니다.

## 한계와 이후 계획

- 저장은 기기 내부(PlayerPrefs)에만 하며, 서버나 기기 간 연동은 없습니다.
- 업그레이드는 두 종류이고, 몬스터 성장이나 스테이지는 아직 없습니다.
- 오프라인 시간은 기기 시계를 기준으로 계산합니다.
